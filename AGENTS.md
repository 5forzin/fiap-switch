# Instruções do projeto

- A interface, a documentação, os comentários e as mensagens devem usar português brasileiro.
- Preserve os identificadores técnicos existentes e os contratos HTTP, SQL e de configuração.
- O controlador da LAN usa WinRM para consultar, reiniciar e desligar; o ligamento usa Wake-on-LAN.
- Não substitua Wake-on-LAN por chamadas à API de provedores de nuvem.
- Não publique senhas, tokens, arquivos de ambiente ou o conteúdo privado de `runtime/`.
- As instâncias do laboratório devem permanecer ligadas para a apresentação, conforme solicitado pelo usuário.
- Antes de cada commit, confirme a conta GitHub e a identidade efetiva de autor e committer.
- Administrador gerencia contas; suporte tem a mesma operação, sem gerenciar contas; monitor acessa somente um andar.
- Ações de administrador são privadas para sua própria conta, inclusive resultados de comandos e verificações salvas.
- Quantidade indefinida preserva computadores; definir um total nunca remove equipamentos silenciosamente.
